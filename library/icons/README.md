## מה כאן
12 אייקוני SVG סטטיים (עניבת `kubai-icons-static`, default palette #5393FF), נבחרו לשימושי דשבורד:
banknote (הכנסות), hand-coins (רווח), coins, users (לקוחות/עובדים), chart-line (מגמה), chart-funnel (משפך), gauge (ניצולת), circle-alert (התראות), calendar, filter, target (יעדים), clipboard-check (משימות).

## הטמעה ב-HTML Content
- ה-SVG עצמאי לחלוטין: בלי script, בלי תלות חיצונית, בלי fonts. מתאים עקרונית גם למהדורת Secure (inline SVG). **לא נבדק ב-Power BI בפועל** - פילטרים הצהרתיים של SVG (feDropShadow וכד') עשויים להיחסם/להתעלם במהדורות מסוימות; במקרה כזה האייקון ייראה שטוח אבל תקין.
- הטמעה: הדביקו את תוכן הקובץ inline בתוך ה-HTML של הרכיב, והכפילו מירכאות כפולות (`"` -> `""`) ב-DAX. דוגמה מלאה: `snippets/kpi-with-icon.dax`.
- id-ים פנימיים ממוספרים לפי שם האייקון (`-ki-<name>`) כדי למנוע התנגשויות בין אייקונים שונים באותו עמוד. אותו אייקון פעמיים באותו ויז׳ואל = id כפול; בדפדפנים זה מרונדר תקין (ההגדרות זהות), אבל אם רוצים בטיחות מלאה - הוסיפו סיומת ייחודית ל-id-ים בעת ההטמעה.
- החלפת צבע: כל הגוונים נגזרים מ-#5393FF. אפשר להוריד גוון אחר דרך האתר (icons.kubai.design) או לערוך את ה-`stop-color`/`stroke` בקובץ.
- RTL: האייקונים סימטריים/נייטרליים ברובם. אייקונים כיווניים (חצים) לא נכללו בסט הזה; אם מוסיפים - שקלו שיקוף אופקי בהקשר עברי.

## גודל
viewBox כולל שוליים לצל: 24px בקובץ ≈ אייקון "חי" של ~20px. ל-KPI card מומלץ width/height 20-28.
